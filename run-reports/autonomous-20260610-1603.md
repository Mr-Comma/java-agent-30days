## 本轮目标

在已有模块风险等级和审查优先级基础上，为 `/api-docs/analyze` 增加一个确定性的 `reviewPlan` 字段，让 API 文档助手不只给出分析结果，也能输出后续 Agent Planner 可直接消费的审查步骤。

## 修改内容

- 新增 `ApiReviewStep` record，包含 `module`、`priority`、`action` 三个结构化字段。
- `ApiDocAnalysisResponse` 新增 `reviewPlan` 输出字段。
- `ApiDocAnalyzerService` 复用已排序的模块摘要生成审查计划：高风险先审删除接口和误删保护，中风险审写操作校验和回滚，低风险抽查分页筛选和空结果。
- `ApiDocAnalyzerServiceTest` 覆盖高/中/低风险模块的审查动作，以及空 OpenAPI 文档时 `reviewPlan` 为空。
- `README.md` 和 `logs/2026-06-10.md` 更新当前能力与学习记录。
