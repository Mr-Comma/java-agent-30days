## 今日观点
调试面板真正落地时，字段不只需要“能展示”，还需要告诉消费者“下一步该怎么操作”。`interactionHint` 是比 `copyable` 更高一层的轻量交互契约，能帮助前端和 Agent 节点少写硬编码。

## 本轮追加实现
- 为 `GET /api-docs/debug-schema` 的字段元数据新增 `agentAction`。
- `agentAction` 使用稳定英文短语描述 Agent 编排层可执行动作，例如 `route-by-status`、`invoke-suggested-tool`、`bind-prompt-variables` 和 `copy-prompt-preview`。
- 更新服务层、Controller JSON 和 README 契约测试，让调试面板可以同时拿到中文交互提示和机器动作标识。

## 追加观点
中文 `interactionHint` 适合人类和 UI 展示，英文 `agentAction` 更适合工作流节点稳定路由；两者并存能减少前端/编排层从文案里解析意图。

## 下一步追加建议

## 本轮继续实现
- 为 `GET /api-docs/debug-schema` 的字段元数据新增 `targetNode`。
- `targetNode` 把 `agentAction` 映射到具体工作流节点名，例如 `status-router-node`、`tool-dispatch-node`、`input-collector-node`、`prompt-template-node` 和 `prompt-preview-node`。
- 更新服务层、Controller JSON 和 README 契约测试，确保运行时 schema、README 示例和字段表同步。

## 继续验证

## 继续观点
`agentAction` 解决“做什么”，`targetNode` 解决“交给哪个节点做”。两者分开后，Agent 编排层可以稳定路由，而不需要从建议工具名或中文提示里反推节点。

## 下一步继续建议
