## 今日主题
Day 24+：继续把 API 文档助手的 debug schema 从“Runbook 步骤”推进到“责任角色”元数据。

## 本轮实现
- 为 `GET /api-docs/debug-schema` 的字段元数据新增 `escalationOwnerRole`。
- 将已有 `failureEscalation` / `escalationRunbook` / `runbookStep` 再补一层中文责任角色：例如 OpenAPI 输入负责人、API 文档助手值班人、Prompt 输入负责人和 Agent 运行时。
- 同步更新 `ApiDocDebugField`、`ApiDocDebugSchemaService`、Service 精确断言、Controller JSON 断言、README JSON 示例和完整字段表。
- 本轮仍为 metadata-only，不改变 `/api-docs/analyze` 主流程，也不创建任何自动任务。

## 学习点
`failureEscalation` 是稳定的升级目标 key，`escalationRunbook` 是处理手册入口，`runbookStep` 是下一步动作，而 `escalationOwnerRole` 用中文告诉调试面板/值班同学“谁负责处理”。这让 UI 能直接展示责任边界，Agent 编排层仍保留机器可读字段。
