# Day 2 Log

Date: 2026-06-09

## Today

- 目标：在不依赖外部 LLM 密钥的前提下，先跑通一个最小工具调用闭环。
- 方向：让 `/chat` 根据用户 prompt 判断是否需要调用内置工具，作为后续 LangChain4j / Spring AI tool calling 的前置练习。

## Done

- 为 `ChatService` 增加 `time` 工具识别：当 prompt 包含 `time`、`时间` 或 `几点` 时，返回当前 ISO 时间。
- 保留普通 prompt 的 mock Agent 回复，确保没有外部服务也能本地运行。
- 通过注入 `Clock` 让时间工具可测试、可复现。
- 新增单元测试覆盖中文时间问题触发工具调用。
- 更新 README，补充 `curl "http://localhost:8080/chat?prompt=现在几点"` 示例。
- 临时冲刺补充：参考 LangChain4j Tool Calling 的结构思路，把 `ChatService` 里的时间判断抽成 `AgentTool`、`TimeTool` 和 `ToolRegistry`，让服务层不再硬编码具体工具。
- 本轮补充：新增 `agent.chat.role-name` 与 `agent.chat.default-prompt` 配置，mock agent 的角色和空 prompt 默认问题不再硬编码。

## Learned

- 即使还没有真实 LLM，也可以先用 `@ConfigurationProperties` 固化“系统角色/默认提示词”的形态，为后续替换模型调用留出稳定接口。
