- 更新 schema service、Controller JSON 断言、README 契约测试和 README 示例，保证运行时 JSON 与文档继续同步。

- 将路由、人类提示和 prompt 预览类字段标记为 `summary`，将结构化 `reviewPromptVariables` 标记为 `detail`，方便调试面板区分首屏字段和详情字段。
- 更新 schema service、Controller JSON 断言、README 契约测试和 README 示例，说明 `visibility` 只服务 UI 展示，不改变 `/api-docs/analyze` 的业务行为。

## 今日观点
一个给 Agent/前端共同使用的 schema，不只要有机器可读字段名，也应该给 UI 提供人类可读标题和说明。`uiLabel` 可以减少前端重复维护字段名映射，`uiDescription` 则能让调试面板在不解析 README 的情况下展示字段帮助。`visibility` 进一步把字段“是否适合首屏展示”变成后端契约，前端无需猜测哪些调试字段应该默认折叠。
